\section{Requirements Crosswalk}
Topic A's budgeting requirement maps to monthly category CRUD, usage thresholds, server-computed recommendations and approved next-month proposals. Bill analysis maps to recurring-payment inference with source evidence and in-app reminders. Spending insights map to same-period comparisons, category charts and transparent unusual-purchase flags. Task execution is demonstrated by an actual accepted budget update and a separate rejected proposal with unchanged financial arrays. Security evidence includes user ownership, exact approval binding, replay/tamper/expiry rejection, concurrency checks and sanitized decisions. Innovation and interaction are supported by visible tools, citations, exact review, a deterministic no-key path and accessible responsive views. These mappings are evidence references, not predicted scores.
