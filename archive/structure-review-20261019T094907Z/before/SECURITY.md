# Reporting security issues

FinPilot AI is a synthetic competition sandbox. Do not connect real banks or enter financial credentials.

Report a vulnerability through GitHub's **Report a vulnerability** feature when available. If private reporting is unavailable, contact the repository owner privately through their GitHub profile before sharing sensitive details. Public issues should contain only a minimal synthetic reproduction and no exploitable secrets, cookies, approval tokens or real financial records.

The supported version is the current `main` branch. See [security self-assessment](docs/security-self-assessment.md) for implemented controls, verification scope and residual risks. There is no promised response SLA or certification.
